# 生成AIプログラミング共通基盤 (AI Programming Practice)

本リポジトリは、生成AIを活用した開発において、プロンプト、エージェント用ルール、スキルを一元管理するための共通基盤です。
他のプロジェクトから **Git Submodule** として取り込むことで、開発効率の向上と品質水準の均一化を図ることを目的としています。

## ディレクトリ構成（予定・一部移行中）

エージェントが自律的にコンテキストを理解し、適切に動作できるよう、以下の構成で管理します。

- `rules/` : 全体的なコーディング規約やアーキテクチャのルールを配置します。
  - プロジェクト全体で適用すべき制約（例: Vertical Slice Architecture 指針、ハルシネーション対策、**キャラクターペルソナルール (`character_personas.md`)** など）
- `skills/` : 特定のタスクを実行するためのエージェント用手順書（スキル）を配置します。
  - 各スキルはディレクトリ単位で管理し、中に `SKILL.md` を配置します。
  - 計画立案（ギャル）、テスト作成・リファクタ（お嬢さま）、コードレビュー（メスガキ）、ドキュメント作成（のじゃロリ）などの役割別ペルソナ対応スキルを含みます。
- `templates/` : 各プロジェクトで利用できる設定ファイルのテンプレートです。
  - `AGENTS.template.md` : 親プロジェクトのルートに配置する `AGENTS.md` の雛形です。プロジェクト固有の要件や技術スタック、ペルソナモードのON/OFF等を設定できます。


## 導入方法

各プロジェクトには固有の `.agents` 設定（プロジェクト独自のルールなど）が存在することが多いため、本リポジトリは直接 `.agents` として上書きするのではなく、**プラグイン（Plugin）** または **別ディレクトリ** として導入することを推奨します。

### 推奨: Plugins として追加する

AIエージェント（Antigravity等）は `.agents/plugins/<plugin_name>/` 配下にある設定をプラグインとして自動認識します。この仕組みを利用するのが最も簡単でコンフリクト（競合）が起きにくい方法です。

親プロジェクトのルートディレクトリで以下のコマンドを実行し、本リポジトリをプラグインとしてサブモジュール追加します。

```bash
git submodule add <本リポジトリのURL> .agents/plugins/ai_programming_practice
git commit -m "Add ai_programming_practice as an agent plugin"
```
これで、本リポジトリ内の `skills/` や `rules/` が `ai_programming_practice` という名前空間のプラグインとして自動的に読み込まれるようになります（シンボリックリンクは不要です）。

## 管理・運用方法

本リポジトリ内のルールやスキルは、複数のプロジェクトで汎用的に使えるものを中心に管理します。

- **新規スキルの追加**: `skills/<skill_name>/SKILL.md` を作成し、具体的なタスク手順や使用するスクリプトを定義してください。
- **ルールの更新**: 新しいベストプラクティスやアーキテクチャ方針（Vertical Slice Architectureの更新など）が生じた場合は、該当の Markdown ファイルを更新し、各プロジェクト側で `git submodule update` を実行して最新化します。
- **ドキュメント**: 追加したスキルやルールの意図は、AIだけでなく人間が読んでも理解できるように Markdown 形式で簡潔に記述してください。
