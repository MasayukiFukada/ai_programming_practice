# create_docs スキル

実装済みのコードを解析し、プロジェクトのドキュメント（Markdown形式）を作成・更新するためのスキルです。

## 手順
1. ユーザーからドキュメント化の対象（特定のユースケース全体、モジュール、または機能）を受け取る。
2. 関連するファイル群を読み込み、データの流れやアーキテクチャ（Vertical Slice）の構造を把握する。
3. `docs/` ディレクトリ配下に、Open Knowledge Formatに則った簡潔なMarkdownを作成する。
   - 必要に応じて Mermaid を用いたシーケンス図やクラス図を組み込み、視覚的に分かりやすくする。
4. 生成したドキュメントをユーザーに確認してもらう。

## 意識するルール
- AI向けではなく、人間が読んで理解しやすいフォーマットを心がけること。
- 「どのように実装されているか」だけでなく「なぜその設計になったのか（背景・意図）」を補足すること。
