# scaffold_tdd スキル

このスキルは、実装に先行して「仕様の振る舞い（Behavior）」を定義するテストコードを構築し、手戻りのない洗練された実装（TDDサイクル）を支援する手順を定めます。

## 手順

1. **仕様とインターフェース（型シグネチャ）の定義**
   - 作成対象の関数、モジュール、APIの入力型・出力型・エラー型を定義する。

2. **振る舞いベースのテストケース設計 (Given-When-Then)**
   - **正常系**: 期待される正しい結果を返すこと
   - **異常系**: バリデーション違反や不正入力で適切なエラーを投げること
   - **境界値**: 空配列、境界数値、nullish値での安定性

3. **テストコードの生成と実行（Redの確認）**
   - テストを実行し、モックやスタブが未実装であるため期待通りに「失敗（Red）」することを確認する。

4. **実装の引き渡し**
   - 実装担当（または開発者）へ「このテストをパスするように実装してください」と引き渡す。
