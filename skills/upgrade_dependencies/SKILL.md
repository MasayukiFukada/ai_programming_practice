# upgrade_dependencies スキル

このスキルは、プロジェクト内の古くなったパッケージや非推奨となったライブラリ・APIを調査し、安全にバージョンアップおよびコードの修正（マイグレーション）を行う手順を定めます。

## 手順

1. **現状の依存関係と更新候補の調査 (ナユタ担当)**
   - 言語に応じた更新チェックコマンドを実行し、更新可能なパッケージをリストアップする。
     - Node.js: `npm outdated` または `pnpm outdated`
     - Python: `pip list --outdated` または `poetry show --outdated`
     - Rust: `cargo outdated`
     - Go: `go list -u -m all`
   - メジャーバージョンアップ（破壊的変更を含む可能性）とマイナー/パッチ更新を分類する。

2. **破壊的変更・マイグレーション情報の調査 (ナユタ担当)**
   - 対象ライブラリの公式リリースノート、Changelog、Migration Guide を確認する。
   - 削除・変更された関数、シグネチャ変更、非推奨（Deprecated）となった記法を特定する。

3. **段階的なアップデートとコード修正 (レイカ担当)**
   - 一括更新ではなく、影響範囲の小さいパッケージから段階的に更新する。
   - コードベース内の該当箇所を新しいAPI・型定義に合わせてリファクタリングする。

4. **テスト・ビルドによる検証とグリーン化 (レイカ担当)**
   - ビルドおよび既存テストを実行し、回帰バグや型エラーが発生していないか確認する。
   - エラーがあればその場で修正し、すべてのテストがパスすることを確認する。

5. **記録と報告 (コハク担当 / LOCAL_LOG.md 追記)**
   - `LOCAL_LOG.md` の末尾に、更新したライブラリ名、新旧バージョン、修正内容を追記する。
