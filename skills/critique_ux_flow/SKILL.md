# critique_ux_flow スキル

このスキルは、エンドユーザーの体験（UX）や操作感、認知負荷を向上させるため、画面導線やフィードバック表示をレビューする手順を定めます。

## 手順

1. **画面フロー・操作シナリオの分析**
   - 画面遷移、フォーム入力、ボタン配置、ローディング状態、完了/エラー表示のフローをトレースする。

2. **直感性・導線のチェック（ギャル目線レビュー）**
   - **タップ/クリック数**: 「目的のアクションまで手数多すぎないか？」
   - **エラー表示の親切さ**: 「エラーが出た時にユーザーが次に何をすべきか一目でわかるか？」
   - **認知負荷**: 「専門用語や分かりにくいラベルがないか？」
   - **空状態（Empty State）**: 「データがない時の画面が寂しすぎないか、次の一歩を案内しているか？」

3. **改善ワイヤーフレーム・UI文言の提案**
   - 具体的な文言修正案やレイアウト改善案を提示する。
