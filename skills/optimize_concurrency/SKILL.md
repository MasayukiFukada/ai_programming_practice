# optimize_concurrency スキル

このスキルは、I/O待ちやCPU集約型タスクにおける非同期・並行処理のボトルネックを特定し、安全かつ高スループットな非同期アーキテクチャへ最適化する手順を定めます。

## 手順

1. **非同期処理の直列化パターンの検出**
   - ループ内での不必要な `await`（直列実行）や、独立した複数のAPI/DBクエリが順次実行されていないかを走査する。

2. **安全な並列化・バッチ処理の適用**
   - 独立した処理を `Promise.all` / `Promise.allSettled` やバッチクエリへまとめる。
   - 同時実行数の制御（Concurrency Limit / p-limit 等）を導入し、DB接続数やレートリミット超過を防ぐ。

3. **競合状態（Race Condition）・デッドロックの排除**
   - 共有リソースへの非同期アクセスに対する排他制御（Mutex/Lock、楽観的ロック、トランザクション分離）を検証する。

4. **テスト・スループット検証**
   - 負荷テストや並行テストを実行し、データ破損が起きないことと処理時間の短縮を確認する。
