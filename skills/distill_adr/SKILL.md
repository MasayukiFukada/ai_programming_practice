# distill_adr スキル

このスキルは、プロジェクト進行中に下された重要な設計上の意思決定（アーキテクチャ選定、データ構造、規約等）のコンテキストを未来へ引き継ぐため、標準化された ADR（Architecture Decision Record）形式で永続化する手順を定めます。

## 手順

1. **意思決定コンテキストの抽出**
   - 直近の会話、`LOCAL_LOG.md`、または `PLAN.md` から、選定された技術、比較検討された代替案、トレードオフの議論を抽出する。

2. **ADRフォーマットへの整理**
   - 以下の標準フォーマット（MADR準拠）にまとめる。
     - **タイトル**: `docs/adr/NNNN-短く明確なタイトル.md`
     - **ステータス**: `Proposed` / `Accepted` / `Superseded`
     - **コンテキスト（背景・課題）**: なぜこの決定が必要になったのか
     - **検討した選択肢**: 選択肢A vs 選択肢B
     - **決定事項と理由**: なぜそれを採用したのか
     - **プラスの影響 / マイナスの影響（トレードオフ）**: メリットと許容したコスト

3. **ドキュメントの保存**
   - プロジェクトの `docs/adr/` 配下に連番ファイル（例: `0001-use-vertical-slice-architecture.md`）として保存する。
