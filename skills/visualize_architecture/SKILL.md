# visualize_architecture スキル

このスキルは、コードの構造や通信の流れを視覚的に理解しやすくするため、標準的な Mermaid ダイアグラムを自動描画・ドキュメント化する手順を定めます。

## 手順

1. **可視化対象の選定と解析**
   - **システム構成・モジュール関係**: コンポーネント図 / 依存グラフ
   - **API / ユースケースフロー**: シーケンス図（Client ➡️ Controller ➡️ Service ➡️ DB）
   - **データ構造**: ER図（Entity Relationship Diagram）
   - **ステート遷移**: 状態遷移図（State Diagram）

2. **Mermaid ダイアグラムの生成**
   - 構文エラー（特殊文字や括弧のエスケープ漏れ）を防ぐ構文規則に則り、見やすく整った Mermaid コードを生成する。

3. **ドキュメントへの埋め込み・解説の付与**
   - `docs/` 配下の仕様書や `README.md` に図を埋め込み、コハクの分かりやすい解説を添えて提示する。
