# setup_project_agents スキル

このスキルは、新規プロジェクトや既存プロジェクトにAI開発用設定を導入する際に、対話形式でプロジェクト設定をヒアリングし、`AGENTS.md` や `.gitignore` などの環境ファイルを整備するためのものです。

## 実行条件
- ユーザーから「プロジェクトのセットアップをしたい」「AGENTS.mdを作成したい」といった依頼があった際に発動する。

## 手順
1. **テンプレートの確認:**
   - `templates/AGENTS.template.md` を読み込み、埋めるべき項目（目的、背景、技術スタックなど）を把握する。

2. **情報収集 (インタビュー):**
   - ユーザーに対して対話形式で質問を行い、プロジェクトの要件をヒアリングする。
   - 質問例: 
     - プロジェクトの目的・背景は何か？
     - 期待するAIの役割は？
     - 使用する技術スタック（バックエンド、フロントエンド、DBなど）は？

3. **付随ファイルの確認と提案:**
   - 対象ディレクトリを確認し、`.gitignore` ファイルが存在するかチェックする。
   - 存在しない場合、ヒアリングした技術スタックに合わせた `.gitignore` の作成を提案する。

4. **ファイルの生成・適用:**
   - 収集した情報をもとに `AGENTS.md` と `.gitignore` の内容を生成し、ユーザーにプレビューを提示する。
   - ユーザーの承認を得た後、ファイルとして保存する。

## 意識するルール
- ユーザーの手間を減らすため、技術スタックを聞いたら一般的な構成を推測して提案する。
- テンプレートのフォーマットを維持しつつ、不要な空欄は残さずに整理して出力する。
