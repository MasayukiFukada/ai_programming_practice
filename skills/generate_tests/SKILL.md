# generate_tests スキル

このスキルは、対象コードのテスト（主に単体テスト）を自動生成するためのものです。

## 手順
1. ユーザーからテスト対象のファイル（および対象の言語・テスティングフレームワーク）を受け取る。
2. 対象コードの依存関係（モックすべき外部APIやDBアクセス）を特定し、適切なモック/スタブの戦略を立てる。
3. 正常系だけでなく、異常系（エラーハンドリング）やエッジケース（境界値など）をリストアップし、テストケース案を作成する。
4. ユーザーの合意を得た後、テストコードを生成してファイルに書き出す。

## 意識するルール
- ドメインロジックやユースケースのテストを重点的に行うこと。
- モックの設定は簡潔に保ち、テスト自体の可読性を落とさないこと。
