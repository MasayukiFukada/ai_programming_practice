# optimize_complexity スキル

このスキルは、コードベース全体を俯瞰し、過剰に肥大化したCCN（循環的複雑度: Cyclomatic Complexity Number）の激減や、計算量（Big-O）・アルゴリズムの効率化、構造的負債の解消を行うための専門スキルです。

## 手順
1. **全体俯瞰とメトリクス分析**:
   - 対象ディレクトリ・モジュール群の依存関係グラフ、制御フロー、CCN（循環的複雑度）、ネスト深度、計算量ボトルネック（$O(N^2)$ ループ等）を静的解析・俯瞰調査する。
2. **ボトルネック・複雑度原因の特定**:
   - 複雑度の高い巨大関数（CCN > 10、多重ネスト、複雑な条件分岐の組み合わせ）、循環依存、不要な再計算、非効率なデータ探索箇所を特定する。
3. **根本的構造改善案の策定**:
   - 早期リターンによるネスト解消、ルックアップテーブル / Map への置き換え、ストラテジーパターン / ポリモーフィズム適用、純粋関数への階層化分割、データ構造の最適化（Hash / Set 等による $O(1)$ 化）を設計する。
4. **改善前後のメトリクス提示と合意**:
   - リファクタリング前後の CCN 予測値、計算量変化、構造の明瞭さをユーザーに提示し、合意を得てコードを更新する。
5. **後続連携**:
   - 局所的な副作用分離や境界値テストの追加が必要な場合はレイカ（実装・テスト担当）にバトンタッチする。

## 意識するルール
- `rules/ai_coding_principles.md` の原則（コンテキストの最小化、関数型アプローチ、CCN 10以下・推奨3以下）を徹底する。
- パッチ当て（局所的な対症療法）ではなく、全体構造が美しく破綻のないアーキテクチャを目指す。
- 成果物コード・コミット・ドキュメント本文にはキャラクター口調を絶対に混ぜず、プロフェッショナルな記述を徹底する。
