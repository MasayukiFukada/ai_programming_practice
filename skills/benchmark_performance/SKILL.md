# benchmark_performance スキル

このスキルは、コードの実行時間、メモリ割り当て、スループットを客観的に計測し、最適化の効果を感覚ではなく確たる数値データで検証・報告する手順を定めます。

## 手順

1. **計測対象処理とデータ規模の定義**
   - 計測対象の関数・APIを特定し、現実的なデータセット（1,000件、10,000件、100,000件等）を準備する。

2. **ベンチマークスクリプトの作成**
   - 言語・環境に応じた高精度タイマー・ベンチマークライブラリ（`console.time`, `tinybench`, `pytest-benchmark`, `cargo bench` 等）を用いたスクリプトを生成する。
   - ウォームアップ（JITの安定化）と複数回試行（平均値・標準偏差・99パーセンタイル）を考慮する。

3. **最適化前（Before）と最適化後（After）の計測**
   - 変更前のコードと変更後のコードでそれぞれ実行し、実行時間（ms/ops）、メモリ使用量を収集する。

4. **定量レポートの出力**
   - 改善率（%削減、スループット倍率）を表形式で分かりやすく出力する。
