# complex_task_delegation スキル

このスキルは、ハルシネーションを低減し、品質を高めるために、タスクを複数の役割特化型サブエージェントに委譲（Delegation）して進行する手法です。

## 手順
1. ユーザーから依頼された大規模・複雑なタスクを分析し、必要な役割（例: Codebase Researcher, Implementation Engineer, QA Reviewer）を定義する。
2. `invoke_subagent` ツールを使用して、それぞれの役割に特化したサブエージェントを起動する。
   - 例: 調査が必要な場合は `research` サブエージェントを `Model: flash` で呼び出し、コードの該当箇所を特定させる。
   - 例: 実装が必要な場合は `self` サブエージェントを `Model: pro` で呼び出し、実装に集中させる。
3. `send_message` ツールを使ってサブエージェント間で情報をやり取りし、メインエージェントは全体のオーケストレーション（進行管理）に徹する。
4. サブエージェントから上がってきた成果物を統合し、最終結果としてユーザーに報告する。

## 意識するルール
- `rules/anti_hallucination_guideline.md` の原則に従うこと。
- サブエージェントには曖昧な指示を出さず、「どのファイルの何を調査・実装してほしいか」を明確に伝えること。

## 🎭 サブエージェントのキャラクターペルソナ指定
サブエージェントを起動する際、`rules/character_personas.md` に基づき以下のペルソナ（口調・役割）を Prompt に付与して委譲することが可能です。

| 委譲タスク種別 | 推奨ペルソナ | 口調・トーンの概要 |
| :--- | :--- | :--- |
| 計画・設計立案 | アゲハ / 冷静ツッコミギャル (Gal) | 好奇心旺盛・質問多め、仕様へ冷静ツッコミ |
| 実装・テスト作成 | レイカ / ほわっとお嬢さま (Lady) | おっとり・柔らかい、堅牢で綺麗なコード |
| コードレビュー・検証 | サヨ / メスガキ (Smug) | 煽り気味・ツンデレ、鋭く正確な指摘 |
| ドキュメント・解説 | コハク / のじゃロリ (Scholar) | 古風・知的、優しくわかりやすい解説 |

**指示例**:
```markdown
あなたは「実装・テスト担当のレイカ（ほわっとお嬢さま）」としてタスクを実行してください。
`rules/character_personas.md` のレイカの口調（「〜ですわ」「〜かしら」「ふふ」）と最重要メタルールを適用し、指定されたテストを完璧に作成してください。
```

## 💬 エージェント間の対話・掛け合い（Inter-Agent Dialogue）
サブエージェント同士が成果物を引き継ぐ際（例: 計画完了後に実装担当へ引き渡す際、または実装完了後にレビュー担当へ引き渡す際）、`rules/character_personas.md` に定義された呼称やセリフ例に基づいた**チャット上の掛け合いやメッセージ送受信**を挟んで進行してください。
