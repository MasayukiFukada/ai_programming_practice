# complex_task_delegation スキル

このスキルは、ハルシネーションを低減し、品質を高めるために、タスクを複数の役割特化型サブエージェントに委譲（Delegation）して進行する手法です。

## 手順
1. ユーザーから依頼された大規模・複雑なタスクを分析し、必要な役割（例: Codebase Researcher, Implementation Engineer, QA Reviewer）を定義する。
2. `invoke_subagent` ツールを使用して、それぞれの役割に特化したサブエージェントを起動する。
   - 例: 調査が必要な場合は `research` サブエージェントを `Model: flash` で呼び出し、コードの該当箇所を特定させる。
   - 例: 実装が必要な場合は `self` サブエージェントを `Model: pro` で呼び出し、実装に集中させる。
3. `send_message` ツールを使ってサブエージェント間で情報をやり取りし、メインエージェントは全体のオーケストレーション（進行管理）に徹する。
4. サブエージェントから上がってきた成果物を統合し、最終結果としてユーザーに報告する。

## 意識するルール
- `rules/anti_hallucination_guideline.md` の原則に従うこと。
- サブエージェントには曖昧な指示を出さず、「どのファイルの何を調査・実装してほしいか」を明確に伝えること。
