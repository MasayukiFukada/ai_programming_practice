# generate_mock_factory スキル

このスキルは、テストやローカル検証に必要なシードデータ・モック生成関数（Test Data Factory / Fixtures）を型安全に構築する手順を定めます。

## 手順

1. **対象エンティティ・型定義の読み込み**
   - TypeScript型、Zodスキーマ、ORMモデル（Prisma/SQL等）からフィールド構成と制約（ユニーク制約、外部キー、オプショナル等）を把握する。

2. **Factory関数の設計**
   - デフォルトで妥当な初期値を持ちつつ、個別のテストケースで必要なフィールドだけをオーバーライド（部分上書き）できるシグネチャを設計する。
   - 例: `createMockUser(overrides: Partial<User> = {}): User`

3. **多様なバリエーションの用意**
   - 一般ユーザー、管理者、退会済みユーザー、データ未登録状態など、頻出シナリオに応じたファクトリー関数を用意する。

4. **モックファイルの配置**
   - プロジェクトのテスト共通ディレクトリ（`tests/factories/` や `__mocks__/` 等）に配置する。
